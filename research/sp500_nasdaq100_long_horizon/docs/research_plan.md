# P0 研究计划（预先规定）

对象：SPX、NDX，美元、分红再投资的 gross total return 月末观察值。
检验假设：仅用过去12个月收益与波动率的 OLS/Ridge/Elastic Net，是否改善成熟标签历史均值基准的样本外误差。
期限36/60/84/120个月；y=12/H*log(TR[t+H]/TR[t])，CAGR=expm1(y)。
同时构造 CPI 实际收益、相对收益、同口径 trailing PE 对数变化历史标签，缺字段时保留缺失。

按日历月份精确配对；特征使用截至预测日的观测，预测定义为月末收盘后、下一时段使用。
总收益水平本身必须是当时可得版本。无修订历史证明的回溯序列禁止当作实时特征。
宏观/盈利等外部特征在P0不进入模型，另提供按 observation/release/vintage 过滤的 as-of 接口。

扩展窗口：训练标签终点严格早于预测日（边界相等亦排除）；可配置额外 embargo 和滚动窗口。
训练最少60个有效成熟标签，四模型使用同一训练行和评估起点。
超参数预先固定于配置，不进行数据驱动选择，无随机切分，无全样本预处理。
2010-01-31起为预先指定在线样本外评估区间；先前测试起点的标签在成熟后允许进入以后训练，
这是在线更新而非永远冻结测试集。评估结果不得用于修改特征/参数后继续称原区间为独立测试集。
合成流程只验证工程，不能支持上述经济假设。真实样本不足时跳过并记录原因。

指标：年化对数收益 RMSE、MAE、方向命中率、相对同期历史均值的样本外R²、逐期误差。
报告标签数及贪心选取互不重叠的评估区间数量，不把它当作独立市场周期。
P0不提供参数显著性/预测区间/策略收益；HAC/区块自助推断、稳健性检验留P1，未执行前不声称统计显著。
验收：关键公式、时间对齐、未成熟标签隔离、未来扰动不变性、训练内标准化、所有模型与CLI集成测试通过。
